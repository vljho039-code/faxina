# Faxina 🧽

Rotação da faxina do escritório. Abra **https://vljho039-code.github.io/faxina/** no celular e instale:

- **Android (Chrome):** menu ⋮ › **Instalar app**
- **iPhone (Safari):** **Compartilhar** › **Adicionar à Tela de Início**

Cada pessoa entra com **usuário e senha**. O admin cria os logins no **Painel admin**
(ou eles são criados todos de uma vez pelo script da planilha) e passa a senha provisória;
no primeiro acesso a pessoa cria a própria senha.

O admin pode: adicionar/remover pessoas (com login), gerar senha nova, escolher quem é admin,
mudar a ordem da rotação, criar/renomear tarefas e mudar os dias, definir quem faz o quê num dia,
ausências, feriados, início da rotação e apagar trocas.

Os dados ficam numa Planilha do Google; a URL do script vai em [`config.js`](config.js).
Sem ela, o app roda em modo demonstração. O script da planilha fica no repositório privado.
